JG LAB PANEL

WAVESHARE ESP32-S3 · 7" TOUCH · 480×800 PORTRAIT

1. Branche le port USB-C UART du panneau au Mac/PC.

2. Clique sur Installer JG LAB Panel.

3. Une fois flashé, configure le Wi-Fi depuis l’assistant USB ou le point d’accès JG LAB Panel Setup.

Utilise Chrome ou Edge sur ordinateur : Web Serial est requis. Cette page doit être ouverte en HTTPS.

Si la carte n’apparaît pas : maintiens BOOT, appuie brièvement sur RESET, puis relâche BOOT.
